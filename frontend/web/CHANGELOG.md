# 프론트엔드 변경 내역

프론트엔드 릴리스에 포함되는 사용자 기능과 주요 변경을 기록합니다.
버전의 기준은 이 디렉토리의 `package.json`이며, Git 태그는 `frontend-vX.Y.Z` 형식을 사용합니다.
항목을 작성한 것만으로 배포가 완료된 것은 아닙니다. 배포 완료 여부와 커밋은 GitHub Release의 배포 기록에서 확인합니다.

## 2.2.0

### 주요 기능

- Google·Apple 로그인과 최근 로그인 방법 표시를 추가합니다.
- 피드·댓글에서 작성자를 신고·차단하고, 설정에서 차단 목록을 조회하거나 차단을 해제할 수 있습니다.
- 관리자 신고 심사, 콘텐츠 숨김·해제와 사용자 정지·해제 기능을 추가합니다.
- 이용약관·개인정보처리방침 열람과 서버가 요구할 때의 이용 동의 흐름을 추가합니다.

### 개선 및 수정

- 랜딩·체험과 로그인 안내에서 로그인 방법 선택 화면으로 이동하도록 통일합니다.
- 전역 배경을 흰색으로 지정하고 피드 본문의 불필요한 간격을 제거합니다.

## 2.1.1

### 개선 및 수정

- PC에서 마우스 휠로 피드 카테고리를 가로 스크롤할 수 있도록 합니다.
- URL로 카테고리를 선택하거나 브라우저 뒤로·앞으로 이동하면 선택된 항목이 보이도록 카테고리 목록을 자동 스크롤합니다.
- 카테고리 글자 크기와 항목 사이 간격을 줄여 한 화면에서 더 많은 항목을 확인할 수 있도록 합니다.
- 랜딩의 주 버튼과 하단 고정 버튼을 피드 이동으로 변경하고, 로그인 없이 구경할 수 있음을 안내합니다. 직접 만들기 버튼은 보조 행동으로 나란히 배치하고 중복 안내를 줄입니다.

## 2.1.0

### 주요 기능

- 네컷만화를 만드는 동안 피드나 앨범 등 다른 화면을 이용할 수 있습니다. 생성이 끝나면 알림에서 완성된 만화를 바로 확인할 수 있으며, 새로고침 후에도 진행 상태를 이어서 확인합니다.
- 작업 상태와 결과를 토스트 알림으로 안내합니다. 만화 생성 진행과 완료·실패, 피드 게시·삭제 등의 결과를 화면에서 확인할 수 있습니다.
- 설정에서 닉네임과 프로필 사진을 함께 수정할 수 있습니다. 기본 프로필 이미지 10종 중 하나를 선택하거나 원하는 사진을 업로드할 수 있습니다.

### 개선 및 수정

- 피드에서 바로 네컷만화를 작성하고, 생성 요청 후에는 작성 전 화면으로 돌아갈 수 있도록 합니다.
- 만화 생성에 실패해도 작성한 내용을 유지해 다시 시도할 수 있도록 합니다.
- 프로필 저장 중 중복 제출과 편집창 닫기를 막고, 저장 실패 시 입력한 내용을 유지해 다시 시도할 수 있도록 합니다.

## 2.0.1

### 주요 기능

- 피드 상세 화면에서 목록으로 돌아오면 기존 목록과 스크롤 위치를 복구합니다. 카테고리나 정렬을 변경하면 스크롤을 초기화합니다.
- 피드 목록에 새로고침 버튼을 추가해 최신 피드를 다시 불러올 수 있도록 합니다.

### 개선 및 수정

- 피드 상세에서 뒤로가기가 잘못 동작하던 버그를 수정합니다. 피드 목록에서 진입한 경우 이전 화면으로 돌아가고, 직접 진입한 경우 피드 목록으로 이동합니다.

## 2.0.0

### 주요 기능

- 홈을 공개 피드로 개편합니다. 로그인 없이 피드 목록과 상세를 조회하고, 카테고리와 최신순 또는 인기순으로 탐색할 수 있습니다. 목록과 댓글에 더 보기를 제공합니다.
- 네컷만화를 카테고리에 맞춰 피드에 게시할 수 있습니다. 내 피드는 삭제할 수 있고, 만화 상세에서 게시 상태를 확인할 수 있습니다.
- 피드에 좋아요를 추가하거나 취소하고, 댓글을 작성하거나 내 댓글을 삭제할 수 있습니다. 로그인하지 않은 사용자가 참여하려 하면 로그인 안내를 표시합니다.
- 피드 링크를 클립보드에 복사해 공유할 수 있습니다.
- 내 네컷만화는 별도의 앨범 탭에서 모아 볼 수 있도록 이동하고, 하단 탐색 메뉴를 개편합니다.
- 설정에서 프로필 이미지와 닉네임을 표시하고 닉네임을 수정할 수 있습니다. 입력 검증과 서버 오류 안내를 제공합니다.

### 기존 사용 방식 변경

- 기존 일기 공유 기능과 `/shares/:shareId` 페이지를 종료합니다. 이전에 발급한 공유 URL은 더 이상 프론트엔드에서 지원하지 않습니다.
- 기본 주소 `/`는 피드를 표시하고, 기존 내 만화 모아보기는 `/album`에서 제공합니다.

### 개선 및 수정

- 첫 방문에는 랜딩 페이지를 안내하고, 이후에는 로그인 여부와 관계없이 공개 피드를 탐색할 수 있도록 진입 흐름을 변경합니다.
- 공개 피드의 세션 복구와 토큰 갱신 대기를 통합하고, 좋아요 변경 요청에 CSRF 토큰을 반영합니다.
- 만화 상세 화면을 피드 게시 흐름에 맞춰 개편하고, 댓글 입력과 로딩, 오류 및 재시도 안내를 보완합니다.

### 내부 개선

- 피드 목록, 상세, 댓글 목록, 발행과 좋아요 변경의 요청 시도를 PostHog에서 기록합니다. 첫 페이지와 더 보기를 구분하고, 토큰 갱신에 따른 내부 재요청은 중복 집계하지 않습니다.
- 클릭으로 카테고리가 실제 변경될 때 선택한 카테고리와 이전 카테고리를 기록합니다.
- 기존 체험 및 앨범 이벤트와 함께 로그인 상태별 활동 사용자를 분석할 수 있도록 이벤트에 인증 상태를 추가하고, 사용자 프로필에 닉네임을 연동합니다.

## 1.1.0

### 주요 기능

- 랜딩 페이지를 `우리끼리 통하는 네컷만화` 브랜드에 맞춰 개편합니다. 친구, 동료, 학교에서의 이야기와 만화 예시, 실제 공유 사례와 이용 현황을 보여주고, 로그인 없는 1회 체험을 랜딩 페이지에서 바로 시작할 수 있도록 통합합니다.
- 기본 주소로 접속하면 로그인 이력이 없는 사용자는 랜딩 페이지로, 로그인 이력이 있는 사용자는 세션 상태에 따라 홈 또는 로그인 화면으로 안내합니다. 로그인 상태 확인에 실패하면 다시 시도할 수 있도록 안내하고, 로그아웃 후에도 로그인 이력을 유지합니다.
- 만화 상세 화면에 이미지 복사 버튼을 추가합니다. 이미지를 클립보드에 복사해 다른 앱에 붙여넣을 수 있으며, 복사 완료 상태와 지원하지 않는 환경 및 실패 상황을 안내합니다.

### 개선 및 수정

- UX 라이팅을 네컷만화 중심으로 개선합니다. 로그인, 홈, 작성, 생성, 상세 화면의 문구를 정리하고, 오류와 제한 상황에서 다음 행동을 안내합니다. UX 라이팅 기준과 최종 문구도 문서화합니다.
- 작성 화면에 입력 예시와 인물 특징을 표현하는 팁을 추가하고, 제출 버튼을 `네컷만화 만들기`로 변경합니다.
- 로그인 화면의 일러스트와 배치를 개선하고, 작은 화면에서도 내용을 스크롤할 수 있도록 보완합니다.
- `우리끼리 통하는 네컷만화` 브랜드 메시지를 사이트 메타데이터와 PWA 앱 정보에 반영하고, 공유 미리보기 이미지를 교체합니다.
- 이미지 저장 파일명을 `하루들_날짜_제목.webp` 형식으로 변경합니다. 파일명에 사용할 수 없는 문자를 처리하고 제목을 최대 20자로 제한합니다.
- 작은 화면에서 설정 카드의 내용이 잘리는 문제를 수정합니다.
- iOS에서 일기 작성 입력창을 선택할 때 화면이 자동으로 확대되는 문제를 수정합니다.
- 홈의 만화 썸네일을 정사각형으로 조정해 이미지가 잘리지 않도록 하고, 홈과 설정 화면의 상단 여백과 하단 네비게이션 높이를 줄입니다.
- 파비콘과 PWA 앱 아이콘을 교체하고, 로고 이미지를 WebP로 변환해 용량을 줄입니다.
- 이미지 복구 안내를 종료하고 임시 공지 배너와 팝업을 제거합니다.

### 기능 종료

- 연속 기록(스트릭) 기능을 종료하고 홈의 연속 기록 표시를 제거합니다.

### 내부 개선

- 이미지 로딩과 저장, 일기 생성, 조회, 삭제, 공유 실패 및 JavaScript 예외를 PostHog에서 추적하도록 보완합니다. 이미지 복사 성공 이벤트와 실패 오류도 추적하며, 예상된 제한, 사용자 취소 및 로그인하지 않은 사용자의 인증 안내는 수집에서 제외합니다.
- TypeScript 컨벤션과 타입 안전성 린트 규칙을 추가하고, 외부 값의 타입 검증을 보완합니다.
- 화면 문구를 페이지별 상수로 분리합니다.
- 검색엔진 크롤링 규칙을 추가해 인증, 개인 일기, 설정, 관리자, 공유 일기 및 게스트 체험 결과 경로의 크롤링을 제한합니다.
- 이미 확보한 인증 토큰을 재사용하고, 로그인 이력 저장소에 접근할 수 없는 환경에서도 랜딩 화면을 표시하도록 보완합니다.

## 1.0.0

프론트엔드 버전 이력을 관리하기 시작하는 첫 기준 버전입니다.
기존에 개발한 주요 기능을 함께 기록하며, 과거 배포를 소급해서 릴리스하지 않습니다.

### 주요 기능

- 카카오 로그인과 로그아웃, 프로필 조회를 제공합니다.
- 일기 작성과 네 컷 이미지 생성 진행 상태, 생성된 일기 상세를 보여줍니다.
- 홈에서 일기를 조회하고 공유 링크로 일기를 확인할 수 있습니다.
- 로그인 전 일기 생성 체험과 PWA 설치 안내를 제공합니다.

### 버전 관리

- `package.json`의 버전을 빌드 시 번들에 포함하고 설정 페이지에 표시합니다.
- 프론트엔드 릴리스별 Git 태그와 변경 내역을 남기는 기준을 도입합니다.

### 공지

- 일기 이미지 재생성 및 지원 안내 공지가 포함되어 있습니다. 이 버전의 결과물을 재배포하면 공지도 함께 복원됩니다.
