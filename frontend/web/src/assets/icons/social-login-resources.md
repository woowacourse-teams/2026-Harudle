# 소셜 로그인 버튼 리소스

- Kakao: `kakao-login.svg`는 [공식 리소스](https://developers.kakao.com/tool/images/resource/preview/login-complete-ko.svg)의
  심볼 경로를 사용한다. 배경 `#FEE500`과 검정 심볼은 [공식 디자인 가이드](https://developers.kakao.com/docs/ko/kakaologin/design-guide)를 따른다.
- Google: `google.png`는 [공식 버튼 리소스](https://developers.google.com/static/identity/images/signin-assets.zip)의
  Android + Web / Light / Square / No text / @4x 이미지에서 버튼 배경을 제외한
  가운데 G 영역이다. 로고 자체의 비율과 색상은 유지한다.
  서체는 Google Fonts의 Google Sans Medium 중 `Google` 글자만 포함해 제공하며 라이선스는
  `../fonts/OFL.txt`에 있다.
- Apple: `apple.svg`는 [Apple Design Resources](https://developer.apple.com/design/resources/)의
  Sign in with Apple / Left Aligned / White / Medium 원본이다.
  [공식 가이드](https://developer.apple.com/design/human-interface-guidelines/sign-in-with-apple)에
  따라 내부 여백을 자르지 않고 이미지 높이를 버튼 높이에 맞춘다.

최근 로그인 말풍선은 공급자의 버튼과 분리된 하루들 안내다.
