# 하루들 UX 라이팅

명확성이 우선이고, 감성은 필요한 순간에만 담습니다. 콘텐츠 이름은 `네컷만화`로 통일합니다. 기록할 경험을 가리킬 때는 `순간`, 사용자가 입력한 글을 가리킬 때는 `내용`을 사용합니다.

## 문구 관리

화면 문구는 각 페이지의 `copy.ts`에서 관리합니다.

- [로그인 문구](../src/pages/login/copy.ts): 태그라인
- [설정 화면](../src/pages/setting/SettingPage.tsx): 로그인에 사용한 계정의 이름은 `소셜 계정 이름`으로 표시해 서비스에서 수정하는 `닉네임`과 구분합니다.
- [앨범 문구](../src/pages/album/copy.ts): 목록, 빈 화면, 생성량 안내
- [피드 문구](../src/pages/feed/copy.ts): 카테고리 선택. 전체 조회는 `전체`, 선택 영역의 접근성 이름은 `피드 카테고리`로 표시합니다. 개별 카테고리 이름은 서버 응답을 사용합니다. 조회 실패 시 `카테고리를 불러오지 못했어요. 다시 시도해 주세요.`와 `다시 시도` 버튼을 표시합니다. 정렬 선택지는 `최신순`, `인기순`으로 표시합니다. 빈 목록은 `아직 이 카테고리에 공유된 피드가 없어요.`를 표시합니다. 안내는 `첫 번째 피드를 올려보세요!`이며, `네컷만화 고르기` 버튼은 네컷 모아보기로 이동합니다. 피드 조회 실패는 `피드를 불러오지 못했어요`와 오류 메시지, `다시 불러오기` 버튼을 표시합니다.
- [작성 문구](../src/pages/diary-write/copy.ts): 질문, 입력 예시, 안내, 팁, 입력 오류
- [생성 결과 안내](../src/shared/errorMessage.ts): 전역 토스트에 표시할 생성 실패 메시지와 다음 행동 안내
- [상세 문구](../src/pages/diary-detail/copy.ts): 줄거리, 피드 게시, 공유, 저장, 삭제. `publishedFeedId`가 null이면 `피드에 올리기`, 피드 ID가 있으면 `피드 삭제하기`를 표시합니다. 피드 삭제는 확인 모달에서 원본 네컷만화가 유지됨을 안내하고, 성공하면 다시 게시할 수 있습니다.
- [피드 게시 문구](../src/pages/feed-post/copy.ts): 일기 상세에서 이미지 주소와 게시 여부를 전달받아 원본 만화, 카테고리 선택, `피드에 올리기` 버튼을 표시합니다. 카테고리는 자동 선택하지 않으며 직접 선택해야 게시할 수 있습니다. 게시 중에는 `피드에 올리는 중...`을 표시하고 선택과 중복 제출을 막습니다. 전달값이 유효하지 않거나 이미 게시된 경우 접근을 막습니다. 카테고리 조회 실패는 `다시 불러오기`로 재시도하고, 게시 실패는 알림창으로 안내하고 선택을 유지합니다.
- [피드 상세 문구](../src/pages/feed-detail/copy.ts): 조회 실패는 `피드를 불러오지 못했어요`와 오류 메시지, `다시 불러오기` 버튼을 표시하고, URL에 피드 ID가 없으면 `삭제되었거나 존재하지 않는 피드예요.`를 표시합니다. 댓글 빈 목록은 `아직 댓글이 없어요.`와 `첫 번째 댓글을 남겨보세요!`를 표시합니다. 댓글 조회 실패는 `댓글을 불러오지 못했어요`와 작은 `다시 불러오기` 버튼을 표시하고, 상세 오류 메시지는 화면에 표시하지 않습니다. 댓글은 다음 페이지가 있을 때 하단에 보조 버튼 `더 보기`를 표시합니다. 추가 조회 중에는 기존 댓글을 유지하고 버튼을 `불러오는 중...`으로 표시하며 비활성화합니다. 추가 조회 실패는 `댓글을 더 불러오지 못했어요. 다시 시도해 주세요.`를 알림창으로 안내하고 같은 커서로 재시도할 수 있습니다. 마지막 페이지에서는 버튼을 숨기며, 첫 조회 실패의 재시도 시 댓글만 다시 조회합니다. 댓글 작성 실패 시 `댓글을 남기지 못했어요. 다시 시도해 주세요.`를 표시하며, 입력한 내용을 유지하고 작성 버튼으로 다시 시도할 수 있습니다. 본인 댓글만 `댓글 관리`에서 `댓글 삭제`를 제공하며, `이 댓글을 삭제할까요?`와 `삭제한 댓글은 되돌릴 수 없어요.`를 표시합니다. 삭제 성공 후 목록에서 제거하고 댓글 수를 갱신합니다.
- [랜딩 문구](../src/pages/landing/copy.ts): 브랜드 소개, 결과 예시, 공유 경험, 공개 피드 미리보기, 체험 안내
- [게스트 체험 문구](../src/pages/landing/trialCopy.ts): 1회 체험 작성, 생성, 결과, 로그인 유도
- [차단 확인 문구](../src/shared/block/copy.ts): `{닉네임}님이 작성한 피드와 댓글을 더 이상 볼 수 없어요.`로 안내합니다. 전송 중에는 `차단 중…`을 표시하고 버튼과 창 닫기를 잠급니다.
- [차단 목록 문구](../src/pages/setting/copy.ts): 해제 성공·실패는 기존 토스트로 안내합니다. 목록 조회 실패는 목록 안의 짧은 안내와 새로고침 버튼으로 표시하며, 해제 후 갱신만 실패한 경우에는 목록 조회만 다시 시도합니다.

문구를 수정하면 이 문서도 함께 갱신합니다. 메타데이터는 기존 `index.html`과 `manifest.json`에서 수정합니다.

## 랜딩과 1회 체험

랜딩과 로그인 없는 1회 체험은 `/landing`에서 함께 제공합니다. 페이지 UI, 체험 상태 관리와 API 코드는 `pages/landing/`에 함께 둡니다. 게스트 결과 조회 경로는 `/landing/result/:diaryId`를 사용합니다.

첫 화면의 주 버튼은 `피드 보러 가기`이며 `로그인 없이 바로 구경할 수 있어요.`를 함께 표시합니다. `직접 만들어 보기`는 보조 버튼으로 두고 피드 버튼과 가로로 나란히 배치합니다. 중복되는 체험 안내는 제거하고 두 버튼 아래 안내를 두 줄로 모읍니다. `이 화면으로 돌아오려면 뒤로가기를 눌러주세요.`로 브라우저 뒤로가기를 안내합니다. 피드와 공통 헤더의 이동 동작은 유지합니다.

첫 화면 제목 위의 서비스 이름 소제목은 제거합니다. `우리끼리 통하는 네컷만화` 제목 아래 설명을 `다른 사람들의 네컷만화를 구경하고,`와 `내 이야기도 만화로 만들어 보세요.` 두 줄로 표시합니다. 헤더 로고 옆에는 한글 이름을 추가하지 않습니다. `직접 만들어 보기` 버튼은 랜딩 내부 스크롤 영역만 움직여 체험 입력으로 이동합니다. 문서 전체가 위로 밀리지 않도록 바깥 스크롤은 이동시키지 않고 입력창 초점도 추가 스크롤 없이 전달합니다. 헤더에는 작은 `로그인` 텍스트 링크를 제공합니다. 첫 진입 화면 하단에는 보라색 아래 화살표가 1.8초 간격으로 위아래로 움직여 스크롤을 안내합니다. `아래 예시 보기` 버튼을 누르면 예시 섹션으로 이동합니다. 40px 이상 스크롤하면 화살표를 숨기고, 모션 감소 설정에서는 움직임을 끕니다. 첫 버튼을 지나면 하단 `피드 보러 가기` 버튼이 나타나고 마지막 체험 섹션에 도착하면 숨깁니다.

페이지 흐름은 브랜드 소개, 내용과 네컷 결과 예시, 공유 경험, 공개 피드 미리보기, 체험 입력의 다섯 섹션 순서입니다. 직접 서비스에서 생성한 결과물만 예시 이미지로 사용합니다. 기존 임시 이미지는 랜딩에서 제외했습니다. 사용자가 준비한 친구 생일, 동료 회의, 학교 발표의 실제 네컷만화를 `pages/landing/assets/`에 보관하고 `copy.ts`의 `LANDING_EXAMPLES`에 입력 내용과 함께 연결합니다. 첫 화면은 동료 회의 작품을 대표로 보여주고, 예시 탭은 친구 이야기부터 시작합니다. 선택지는 같은 너비의 독립된 버튼 세 개로 배치합니다. 각 버튼에 보라색 테두리와 아래쪽 그림자를 넣어 누르는 조작임을 보여주고 `눌러서 다른 이야기도 보세요`를 유지합니다. 선택 버튼은 보라색 배경과 체크 표시를, 비선택 버튼은 흰색 배경과 오른쪽 꺾쇠를 사용합니다. 호버 시 살짝 올라가고 누르면 내려가며 키보드 초점 테두리도 표시합니다. 모션 감소 설정에서는 위치 이동을 끕니다. 예시 입력은 괄호 속 외형과 인물 이름을 덜고 핵심 사건·결말만 담은 짧은 두 문장으로 줄입니다. 짧게 적어도 된다는 점을 예시 자체로 보여줍니다. 임시 장면 구성과 실제 결과가 아니라는 안내는 제거합니다. 공유 섹션 제목은 `생성한 만화를 공유해보세요`로 표시합니다. 카카오톡 대화 아래 `우리끼리는 이미 이렇게 나누고 있어요`를 다른 섹션 제목과 같은 크기로 표시하고 `우아한테크코스 교육생들이 슬랙에 올린 네컷만화예요.`로 실제 이용 사례를 소개하며 공식 협업이나 전용 서비스라고 표현하지 않습니다. 공개 피드 미리보기 아래에 기존 이용 현황 박스 `2,000장+ / 만들어진 네컷만화`, `170명+ / 함께하는 사람`을 배치합니다. 사용자가 전달한 대표 수치를 `copy.ts`에 보관하며 현재 API로 자동 갱신하지 않습니다. 집계 기준 확인 전에는 실제 생성자라고 표현하지 않습니다. 숫자는 60% 보일 때 0.9초 동안 한 번 올라가고, 화면을 다시 들어와도 반복하지 않습니다. 스크린 리더에는 최종 수치만 제공하고 모션 감소 설정에서는 즉시 최종 수치를 표시합니다. 슬랙은 `# 그림일기-공유` 채널과 치약 만화 작성자 `이산`, 실제 시각 `오후 1:27`을 표시하고 예시 라벨을 제거합니다. 치약 원본은 크게, 아련한 노래 퀴즈·내 최애를 소개합니다 원본은 100px 썸네일로 표시하고 이모지 반응은 썸네일 오른쪽의 게시물 정보 아래에 배치합니다. 노래 퀴즈 작성자는 사용자가 지정한 `이현`과 직접 제공한 캐릭터 프로필 이미지로 표시합니다. 노래 퀴즈 반응에는 확인되지 않은 수치를 넣지 않고, 최애 만화 반응은 캡처의 9·4개를 합계 13개의 브이 반응으로 묶습니다. 최애 만화 작성자는 사용자가 지정한 `아이큐`와 직접 제공한 캐릭터 프로필 이미지로 표시합니다. 치약 반응은 큰 수부터 웃음 15·와우 6·바보 3·경광등 2, 댓글은 7개로 캡처의 실제 수치를 사용합니다. 실제 답글 `localhost:2080` 하나만 표시합니다. 게시물에는 닉네임만 표시하고 실명은 제거합니다. `localhost:2080` 답글은 사용자가 지정한 닉네임 `초록`과 직접 제공한 28px 캐릭터 프로필 이미지, 캡처의 실제 시각 `오후 1:30`으로 표시합니다. 인용 세로선을 제거하고 밝은 댓글 영역 안에서 프로필 오른쪽에 이름·시간·본문을 정렬합니다. 이름은 14px 굵게, 본문은 15px 보통 굵기로 표시합니다. 전체 댓글 수 7개에서 노출한 1개를 뺀 `댓글 6개 더 보기`를 댓글 아래 작은 안내로 표시하며 작동하지 않는 더 보기 버튼은 만들지 않습니다. 네 컷은 원본 이미지 한 장 위에 `clip-path` 가림막을 두고 순차적으로 사라지게 표시해 이미지 분할·확대로 생기는 이음새를 없앱니다. 작은 게시물의 댓글 수는 각각 9·3개입니다. 처음 보일 때 한 번 메시지와 네 컷, 반응과 수치, 입력 중 표시와 답글, 작은 게시물 순으로 등장합니다. 슬랙의 입력 중 표시는 연출 시작부터 약 2.2초 동안 보이며, 댓글은 2.25초, 댓글 수는 2.6초, 작은 게시물은 2.9초부터 등장합니다. 다시 스크롤해도 반복하지 않으며 모션 감소 설정에서는 처음부터 최종 수치와 전체 내용을 표시합니다. 추가 스크롤 고정·사례 전환은 넣지 않고 슬랙 카드 다음에 공개 피드 미리보기와 이용 현황으로 이어집니다. 메신저 대화는 `공유 장면 예시`로 표시해 실제 사용자 후기로 오해하지 않도록 합니다. 연한 파란 배경, 노란 발신 말풍선, 흰 수신 말풍선, 이름과 사용자가 제공한 캐릭터 프로필, 네컷 이미지 메시지, 장식용 입력줄로 채팅방을 연출합니다. 입력줄은 실제 입력창이나 전송 기능으로 제공하지 않습니다. 이미지 저장은 파일 저장으로 안내하며 사진 앨범에 직접 저장한다고 표현하지 않습니다.

기존 카카오톡 공유 장면·슬랙 사례를 유지하고, 그 아래 체험 섹션 앞에 공개 피드 미리보기를 제공합니다. 제목은 `피드에서`, `네컷만화를 구경해요`를 두 줄로 표시해 피드의 역할을 먼저 안내하고, 설명은 `지금 인기있는 네컷만화 두 개를 먼저 만나보세요.`로 표시합니다. 기존 공개 피드 API의 인기순 상위 두 개를 카드로 배치하고 실제 만화, 카테고리, 실제 좋아요·댓글 수만 표시합니다. 닉네임은 카드와 접근성 이름에서 제외합니다. 순위 배지는 사용하지 않습니다. 카드는 흰 바탕, 연한 회색 테두리, 가벼운 무채색 그림자와 둥근 모서리로 구성합니다. 피드 두 개를 세로로 쌓아 만화를 카드 전체 너비로 크게 보여줍니다. 이미지 아래 한 줄에 회색 카테고리 태그와 작은 좋아요·댓글 수를 배치하며, 공간이 부족하면 줄바꿈합니다. 보라색 바탕과 중복 테두리, 반응 수 위의 구분선은 제거합니다. 기존 이용 현황 박스는 피드 둘러보기 버튼 아래로 옮기고 스타일과 수치 애니메이션을 유지합니다. 카드는 해당 공개 피드 상세로, 아래 보조 버튼 `피드 둘러보기`는 전체 공개 피드 `/`로 이동합니다. 로그인 없이 조회할 수 있습니다. 조회 중에는 `네컷만화를 불러오고 있어요`, 실패 시 `네컷만화 미리보기를 불러오지 못했어요.`와 `다시 불러오기`를 표시합니다. 빈 목록은 `아직 공개 피드에 올라온 네컷만화가 없어요.`로 안내합니다. 어느 상태에서도 체험과 피드 이동을 유지합니다. 첫 화면의 체험 버튼·로그인·예시와 기존 공유 연출은 그대로 둡니다.

마지막 체험 카드의 입력창은 4줄과 `resize: none`을 사용합니다. 이용 안내는 두 문장을 각각 줄바꿈하고 가운데 정렬하며 단어를 중간에 끊지 않습니다. 입력을 시작하면 글자 수를 보라색으로 표시합니다. 빈 상태에서 생성 버튼을 누르면 생성 요청 없이 입력창에 초점을 유지하고 `있었던 순간을 적어주세요`를 안내합니다. 10자 미만 입력도 입력창으로 초점을 돌려 기존 안내를 표시합니다. 카드 아래에는 `이미 만들어 봤나요?`와 밑줄·화살표가 있는 `카카오로 이어서 만들기 →`를 표시합니다. 마지막 섹션 하단 여백을 32px로 줄이고 흰 푸터와 구분선으로 마무리합니다. 푸터에는 하루들 브랜드, 개인정보처리방침(기존 Notion 주소), 문의 메일 `harudle.official@gmail.com`, Instagram `harudle.official`, 저작권 표기를 둡니다. 이용약관은 사용자가 아직 없다고 확인해 링크를 표시하지 않습니다. 하단 여백에는 기기의 safe area를 추가하고 체험 섹션에서는 기존 고정 CTA 숨김을 유지합니다.

체험 질문은 바깥 제목 `최근에 같이 웃었던 순간이 있나요?`로 한 번만 표시하고 제출 버튼은 `네컷만화 만들기`를 사용합니다. 로그인 화면과 같은 두 사람이 네컷만화를 함께 보는 일러스트를 사용합니다. 입력창은 기본 네 줄 높이이며 글자 수만 표시하고, 길이 오류는 제출 시 안내합니다. 빈 입력창의 친구·동료·학교 예시는 5초마다 바뀌고 초점이 있거나 입력을 시작하면 멈춥니다. 버튼 바로 아래 `로그인 없이 한 장 먼저 만들어 보세요!`와 `로그인하면, 하루 3장까지 무료로 이용할 수 있어요.`를 두 줄로 안내합니다. 체험 준비 중이거나 진입에 실패해도 브랜드 소개는 유지하고 체험 영역에서 상태와 재시도를 안내합니다.

첫 화면의 보조 체험 버튼은 생성 중 `만들고 있는 네컷만화 보기`, 성공 후 `완성한 네컷만화 보기`, 체험 소진 후 `로그인하고 계속 만들기`로 바뀝니다. 생성 상태나 결과 확인 영역으로 이동하며, 소진 후에는 카카오 로그인 링크에 초점을 줍니다. 결과와 소진 안내에서는 `카카오로 시작하고 계속 만들기`를 사용합니다. 로그인 이후에 체험 결과가 자동 보관된다고 약속하지 않습니다.

스크롤 애니메이션은 랜딩 내부 스크롤 영역을 기준으로 카드가 화면 안으로 충분히 들어온 뒤 한 번 실행하며 제목과 일반 설명은 움직이지 않습니다. 화면 하단 80px을 제외한 영역에서 카드가 30% 보일 때, 예시 타이핑은 35% 보일 때 시작합니다. 첫 화면의 네 컷은 0.15초 간격으로 등장합니다. 예시는 처음 보일 때와 탭 변경 시 내용 타이핑, 화살표, 네 컷 순서로 표시합니다. 대화는 메시지, 네컷 원본 이미지, 이미지 아래 이모지 반응, 입력 중 표시, 답장 순서로 보여줍니다. 채팅창 등장 후 첫 메시지에 0.25초 여유를 두고, 기본 메시지 간격은 0.65초로 표시합니다. 입력 중 표시는 2.1초 뒤 시작해 0.8초 동안 보여준 뒤 답장으로 이어집니다. 노란 말풍선 안의 점 세 개는 0.12초 간격으로 차례로 4px씩 위아래로 움직이며 0.7초 주기로 반복합니다. 모션 감소 설정에서는 이 연출을 숨깁니다. 이미지 반응은 `😂 1`, `😆 1`의 작은 칩으로 표시하고, 이미지를 보여준 뒤 한 번 등장합니다. 공유 장면 예시의 정적인 반응 표시이며 실제 반응 전송 기능은 제공하지 않습니다. 프로필은 `나`에 모자를 쓴 캐릭터, `친구`에 웃는 캐릭터를 사용합니다. 별도 기능 칩과 사용 방법 섹션은 반복하지 않습니다. 모션 감소 설정에서는 모든 내용을 즉시 표시하고 애니메이션을 사용하지 않습니다. 브라우저가 IntersectionObserver를 지원하지 않아도 콘텐츠와 체험을 이용할 수 있습니다.

게스트 생성 단계도 실제 서버 진행률이 아닌 대기 안내입니다. 오래 기다리는 상황에서는 `예상보다 시간이 걸리고 있어요. 조금만 더 기다려주세요.`로 안내하고 완료를 예고하지 않습니다. 기존 요청 저장, 같은 멱등성 키를 이용한 재시도, 사용 완료 상태는 유지합니다.

## 피드 액션

- 피드 목록은 다음 페이지가 있을 때 하단에 보조 버튼 `더 보기`를 표시합니다. 추가 조회 중에는 기존 목록을 유지하고 버튼을 `불러오는 중...`으로 표시하며 비활성화합니다. 실패하면 `피드를 더 불러오지 못했어요. 다시 시도해 주세요.`를 알림창으로 안내하고, 기존 목록과 `더 보기` 버튼을 유지합니다. 마지막 페이지에서는 버튼을 숨깁니다.

- 공유 버튼은 `피드 공유` 바텀시트를 열고 `링크 복사`를 제공합니다. 해당 피드의 `shareUrl`을 복사한 뒤 바텀시트를 유지하고, 2초 동안 완료 아이콘과 `복사됨`을 표시합니다.

- 본인 피드의 더보기 버튼은 `피드 관리` 바텀시트를 열고 `피드 삭제`를 제공합니다. 확인 모달 제목은 `이 피드를 삭제할까요?`, 설명은 `피드에서만 삭제돼요. 앨범의 원본 네컷만화는 그대로 남아요.`입니다. 처리 중 확인 버튼은 `삭제 중...`으로 표시합니다.

## 신고 접수

피드 목록·상세와 댓글의 타인 더보기에는 콘텐츠 신고와 `작성자 신고`를 제공합니다. 탈퇴한 작성자의
ID가 없으면 작성자 신고는 표시하지 않고 댓글 신고는 유지합니다. 본인 콘텐츠에는 기존 삭제 메뉴를
유지합니다. 비로그인 사용자는 기존 로그인 안내에서 `신고를 접수하려면 로그인해 주세요.`를 확인합니다.
[신고 문구](../src/shared/report/copy.ts)는 사유 선택과 선택 상세 500자를 안내합니다. `접수 중...`에는
입력·중복 제출을 막고, 실패 시 내용과 사유를 유지해 재시도합니다. 성공은 `신고가 접수되었어요.
운영자가 내용을 확인할게요.`, 중복은 `이미 접수된 신고예요. 처음 제출한 사유와 내용은 유지돼요.`로
구분합니다. 성공했을 때 신고창을 닫고 기존 토스트로 안내하며, 실패하면 입력을 유지합니다. 신고가 즉시 제재나 숨김으로 이어진다고 안내하지 않습니다.

## 동작에 맞춘 사용 기준

- 피드 게시·삭제와 네컷만화 삭제가 성공하면 각각 `피드에 올렸어요.`, `피드를 삭제했어요.`, `네컷만화를 삭제했어요.`를 2초 동안 토스트로 표시합니다. 기존 오류 알림의 문구는 유지하며, 만화 생성과 복사 실패 알림은 이번 토스트 전환에서 제외합니다.
- 로그인 화면은 태그라인을 두 줄로 나누어 첫 줄은 26px, `네 컷 만화`는 30px 크기로 표시합니다. 로그인 태그라인에서는 시각적 강조를 위해 띄어 쓰고, 콘텐츠 이름과 메타데이터는 `네컷만화`를 유지합니다. 줄 높이는 1.3이며, `네 컷 만화`를 브랜드 색상으로 강조합니다. 이미지 안의 투명 여백을 제외하고 상단, 로고와 일러스트 사이, 일러스트와 태그라인 사이, 태그라인과 버튼 사이에 화면 높이에 비례하는 여백을 나누어 둡니다. 로고와 일러스트 사이는 가장 넓게, 일러스트와 태그라인 사이는 가장 가깝게 배치합니다. 약관 문구는 12px 크기로 표시하며, 기존 색상과 글자 굵기를 유지합니다. 로고와 일러스트의 최대 폭은 각각 246px, 336px이며 작은 화면에서는 높이와 폭에 맞춰 축소합니다.
- 입력창 위의 작성 안내에서는 공유할 순간과 개인적으로 간직할 기억 모두 적을 수 있도록 안내합니다.
- 홈의 남은 생성량은 월 선택 옆에 짧게 표시하고, 콘텐츠의 편 단위를 사용합니다. 화면에서 이미 드러나는 콘텐츠 이름은 반복하지 않습니다.
- 다른 달을 조회할 때에는 `이번 달` 대신 선택한 연도와 월을 표시합니다.
- 생성 안내 1~4단계는 3초 간격의 대기 안내입니다. 서버가 전달하는 실제 진행 단계나 완료율은 아닙니다. 완료 안내와 상세 화면 이동은 성공 응답 후에만 표시합니다.
- 생성 요청 전에 입력을 세션에 저장하고, 성공한 경우에만 지웁니다. 실패 화면에서는 입력 보존 안내와 구체적인 오류 사유를 함께 보여줍니다. 횟수 제한처럼 별도의 해결 방법이 있는 오류 사유를 숨기지 않습니다.
- 하루 생성 횟수를 모두 사용한 경우에는 즉시 다시 시도하도록 안내하지 않고 입력 보존과 제한 사유를 표시합니다.
- 현재 실패 버튼은 입력을 복원하는 작성 화면으로 이동하므로 `내용 수정하기`를 사용합니다. 동일 입력으로 바로 재시도하는 기능을 추가하면 `다시 만들기`를 사용합니다.
- 브라우저의 이미지 다운로드 동작에는 `이미지 저장`을 사용합니다. 사진 앨범에 직접 저장하는 동작이 제공될 때 `앨범에 저장`을 검토합니다.

첫 화면의 스크롤 안내는 진한 보라색 원형 버튼과 흰색 SVG 화살표를 사용합니다. 문구와 테두리는 제거하고 두 겹의 그림자로 떠 있는 느낌을 주며 화면 아래 24px에 safe area를 더해 배치합니다. 화살표만 위아래 3px 움직이며, 기존처럼 스크롤을 시작하면 숨기고 누르면 예시 섹션으로 이동합니다. 모션 감소 설정에서는 움직임을 끕니다.

## 공통 로그인 안내

로그인 안내 바텀시트 제목은 `로그인하고 계속할까요?`, 주 버튼은 `카카오로 로그인`, 보조 버튼은 `계속 둘러보기`를 사용합니다. 설명은 사용하는 곳에서 전달하며 줄바꿈을 유지합니다. 주 버튼은 로그인 페이지로 이동하고 보조 버튼은 시트만 닫습니다.

피드 좋아요 로그인 안내 설명은 `피드는 로그인 없이 볼 수 있어요.`와 `좋아요를 누르려면 로그인해 주세요.`를 두 줄로 표시합니다. 로그인 완료 표시가 없으면 좋아요 요청 전에 안내를 열며, 기존 인증 요청과 세션 만료 처리에는 영향을 주지 않습니다.

홈 상단의 `네컷만화 만들기` 버튼도 로그인 완료 표시가 없으면 작성 화면으로 이동하는 대신 같은 로그인 안내 시트를 엽니다. 설명은 `피드는 로그인 없이 볼 수 있어요.`와 `네컷만화를 만들려면 로그인해 주세요.`를 두 줄로 표시합니다.

## 첫 방문과 재방문

`/` 첫 방문에는 랜딩을 표시하고, 랜딩이 표시되면 브라우저에 방문 기록을 저장합니다. 이후 `/`에서는 로그인 여부와 관계없이 피드를 표시합니다. 방문 기록은 로그인 이력과 별도로 관리하며 저장소를 사용할 수 없으면 공개 피드 진입을 허용합니다.

하단 메뉴의 `네컷 모아보기`와 `설정`은 로그인 완료 표시가 없으면 이동 대신 로그인 안내 시트를 엽니다. 설명은 `피드는 로그인 없이 볼 수 있어요.`와 `이 기능을 이용하려면 로그인해 주세요.`를 두 줄로 표시합니다. `홈`은 로그인 없이 이동할 수 있습니다.

## 일기 공유 제거

일기 공유 링크 발급과 `/shares/:shareId` 조회 화면은 제거했습니다. 네컷만화를 공유하려면 피드에 게시한 뒤 피드 공유 기능을 사용합니다. 기존 일기 공유 URL은 페이지를 찾을 수 없다는 안내를 표시합니다.

## 프로필 수정

사진 용량 안내는 익숙한 `5MB`로 표시합니다. 파일 선택 시 최대 5,000,000바이트까지 받습니다. 잘못된 파일을 거절하면 기존 사진 선택을 유지하고 오류 이유를 보여줍니다. 기존 사진이 유효하면 닉네임을 저장할 수 있습니다. 사진을 바꾸거나 업로드 미리보기를 표시하지 못하면 `되돌리기`로 기존 사진으로 돌아갈 수 있습니다. 기본 사진의 표시 실패는 대체 이미지를 보여주며, `사진 다시 불러오기`로 재시도할 수 있습니다. 저장과 조회 중에는 창 닫기를 막고, 조회 실패 후에는 `다시 불러오기`로 조회만 재시도합니다.
