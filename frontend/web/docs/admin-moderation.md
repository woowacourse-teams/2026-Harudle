# 관리자 신고 심사·제재

관리자 메뉴의 **신고 관리**에서 접수·반려·처리 완료 목록을 선택합니다. 신고를 누르면 접수 사유와 현재 대상 상태를 확인할 수 있습니다. 삭제되거나 탈퇴한 대상도 남아 있는 신고와 조치 이력은 확인할 수 있으며, 새 제재는 할 수 없습니다.

## 신고 처리와 실제 조치

- **반려 / 처리 완료**: 신고 상태를 종결합니다. 사유를 남기며 종결한 신고는 다시 변경하지 않습니다.
- **콘텐츠 숨김 / 숨김 해제**: 해당 피드나 댓글의 관리자 숨김을 바꿉니다.
- **사용자 정지 / 정지 해제**: 회원 기능 제한을 바꿉니다. 기존 **사용자 관리 → 사용자 상세**에서도 처리할 수 있습니다.

신고 종결과 조치는 각각 실행합니다. 신고를 처리 완료해도 콘텐츠가 자동으로 숨겨지거나 계정이 정지되지 않습니다. 정지를 해제해도 콘텐츠 숨김은 유지됩니다. 숨김을 해제해도 삭제·개인 차단이나 다른 연결된 피드의 관리자 숨김까지 해제되지는 않습니다.

## 실패·동시 처리

조치 전에는 사유를 입력하고 확인합니다. 처리 중에는 입력·중복 제출·창 닫기를 막고, 실패하면 입력을 보존합니다. 변경이 성공한 뒤 화면 갱신만 실패하면 **다시 불러오기**로 조회만 재시도합니다.

다른 관리자가 먼저 변경했다면 자동으로 다시 처리하지 않습니다. 확인창을 닫고 최신 상태를 다시 불러온 뒤, 필요한 조치를 새로 확인합니다.
