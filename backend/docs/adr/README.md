# ADR 작성 가이드

ADR은 하나의 문제를 어떻게 해결하기로 했는지, 왜 그 방법을 선택했는지 기록하는 문서입니다.

1. **제목**에는 결정할 내용을 적습니다.
2. **배경**에는 어떤 문제가 있었는지 적습니다.
3. **고려한 방법**에는 비교한 방법과 각각의 장단점을 적습니다.
4. **결정과 이유**에는 선택한 방법과 그 이유를 적습니다.
5. **실제 동작과 결과**에는 선택한 방법이 어떻게 동작하고 무엇이 달라지는지 적습니다.

처음 읽는 사람도 이해할 수 있도록 쉬운 말로 적습니다. 필요한 내용은 구체적으로 설명하고, 결정과 관계없는 내용은 빼고 적습니다. 작성일이나 상태 같은 별도 메타데이터와 후속 작업 목록은 본문에 넣지 않습니다.
