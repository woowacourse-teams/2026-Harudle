# 2026-08-27 관리자 사용자 검색을 어떻게 구성할 것인가

- 작성일: 2026-08-27
- 작성자: 이산
- 결정 대상: 관리자 사용자 검색 조건과 결과 범위

## 결정

`GET /api/v1/admin/users`는 하나의 검색어로 이름과 사용자 UUID를 검색한다.

- 검색어 앞뒤 공백은 제거하고, 이름은 대소문자를 구분하지 않는 부분 일치로 검색한다.
- UUID 형식의 검색어는 사용자 UUID 완전 일치 조건을 함께 적용한다.
- 검색어가 없으면 전체 사용자를 조회한다.
- 탈퇴 사용자는 포함하고, `guest_sessions`에 연결된 게스트 사용자는 제외한다.
- 가입일 내림차순, 가입일이 같으면 사용자 UUID 내림차순으로 정렬한다.
- 결과에는 사용자 정보와 오늘의 `generationUsage`를 함께 반환한다.

## 결과

- 관리자 화면에서 사용자 검색과 오늘 사용량 확인을 한 번에 처리할 수 있다.
- 탈퇴 사용자와 게스트 사용자의 노출 정책이 명확하다.
- 고정된 보조 정렬 기준으로 페이지 이동 시 결과 순서가 흔들리지 않는다.

## 재검토 조건

- 이름 외에 별도 검색 필터가 필요해지는 경우
- 게스트 사용자도 관리자 화면에서 관리해야 하는 요구가 생기는 경우
