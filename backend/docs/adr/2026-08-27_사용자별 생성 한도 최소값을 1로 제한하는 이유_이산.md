# 사용자별 생성 한도 최소값을 1로 제한하는 이유

- 상태: 채택
- 작성자: 이산

## 결정

사용자별 일일 생성 한도(`daily_generation_limit`, `limitCount`)는 `1` 이상의 정수만 허용한다.
기본값은 기존과 같이 `3`회로 유지한다.

## 이유

`0`을 생성 기능 비활성화 값으로 사용하면 최초 생성 요청 시 `usedCount = 1`, `limitCount = 0`인 사용량 행을 만들려는 경로가 생겨 데이터베이스 제약조건과 충돌할 수 있다.
생성 기능을 중지해야 하는 요구사항이 없는 현재 범위에서는 한도에 `0`이라는 별도 의미를 부여하지 않는 편이 단순하고 안전하다.

## 결과

- 관리자가 `limitCount = 0`을 요청하면 `400 VALIDATION_ERROR`를 반환한다.
- 사용자 도메인, 서비스, Repository, DB에서 `1` 미만 값을 방어한다.
- 기존 DB에 `0`으로 저장된 사용자 한도와 사용량 스냅샷은 마이그레이션에서 `1`로 정리한다.
- 이후 생성 기능 중지 요구사항이 생기면 한도와 분리된 상태값으로 설계한다.
