# 회원 탈퇴 중 이미지 삭제 실패를 어떻게 처리할 것인가

## 결정 (Decision)

회원이 탈퇴할 때 회원의 프로필 이미지와 일기 이미지, 이미지 백업을 삭제한다. 서비스에서 공통으로 사용하는 기본 프로필 이미지는 삭제하지 않는다.

이미지 삭제에 실패해도 탈퇴는 계속 진행한다. 실패한 이미지의 자동 삭제 재시도는 만들지 않는다. 필요한 경우 남은 이미지를 수동으로 삭제한다.

## 근거 (Rationale)

회원이 탈퇴하면 이미지를 복구하거나 별도로 활용할 필요가 없으므로 삭제한다.

탈퇴하는 회원이 많지 않아 삭제에 실패해 남는 이미지도 많지 않을 것으로 판단했다. 자동 재시도 기능을 운영하는 것보다 필요한 이미지를 수동으로 삭제하는 편이 현재 상황에 맞다.

## 결과 (Consequences)

- 이미지 삭제가 실패해도 회원은 탈퇴할 수 있다.
- 삭제에 실패한 이미지는 자동으로 다시 삭제되지 않으며, 저장소에 남을 수 있다.
