# 구글 로그인 연결 해제를 어떻게 처리할 것인가

## 결정 (Decision)

구글 회원이 탈퇴하면 구글 로그인으로 한 번 더 인증한다. 하루들에 가입한 구글 계정과 같은지 확인하고, 인증 과정에서 받은 토큰으로 구글 연결을 해제한다.

구글 연결 해제에 성공한 뒤 하루들 회원 정보 삭제가 실패하면 탈퇴 실패를 알린다. 회원이 다시 탈퇴를 요청하면 같은 구글 계정으로 다시 인증하고 연결 해제와 회원 정보 삭제를 다시 시도한다.

## 근거 (Rationale)

구글 연결을 해제하려면 회원의 구글 토큰이 필요하다. 탈퇴할 때 다시 인증하면 이 목적을 위해 토큰을 계속 보관하지 않아도 된다. 다른 구글 계정의 연결을 해제하지 않도록 가입한 계정과 일치하는지 확인한다.

구글 연결 해제와 하루들 DB 삭제는 함께 되돌릴 수 없다. DB 삭제가 실패하면 회원 정보가 남으므로 회원이 다시 탈퇴할 수 있어야 한다.

## 결과 (Consequences)

- 구글 회원은 탈퇴할 때 구글 로그인을 다시 진행한다.
- 가입한 계정과 다른 구글 계정으로 인증하면 탈퇴를 진행하지 않는다.
- 구글에 다시 로그인할 수 없다면 이 방법으로 탈퇴를 재시도하기 어렵다.
