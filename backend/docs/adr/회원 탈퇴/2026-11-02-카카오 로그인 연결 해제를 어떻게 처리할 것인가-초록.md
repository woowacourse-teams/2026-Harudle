# 카카오 로그인 연결 해제를 어떻게 처리할 것인가

## 결정 (Decision)

카카오 회원이 탈퇴하면 회원의 카카오 사용자 번호와 관리자 키로 연결 해제를 요청한다. 연결 해제를 확인한 뒤 하루들 회원 정보를 삭제한다.

카카오가 해당 회원이 앱에 연결되어 있지 않다고 응답한 경우에도 회원 삭제를 진행한다. 관리자 키 오류나 통신 오류처럼 연결 상태를 확인할 수 없는 경우에는 탈퇴를 중단한다.

카카오 연결 해제에 성공한 뒤 하루들 회원 정보 삭제가 실패하면 탈퇴 실패를 알린다. 서버가 자동으로 다시 삭제하지 않고, 회원이 다시 탈퇴를 요청하면 연결 상태를 확인한 뒤 회원 정보 삭제를 다시 시도한다.

## 근거 (Rationale)

카카오 연결 해제와 하루들 회원 정보 삭제는 별개의 작업이다. 카카오 연결 해제에는 성공했지만 DB 삭제가 실패하면, 회원이 다시 요청했을 때 카카오는 이미 연결되지 않은 회원이라고 응답할 수 있다. 이 경우에도 회원이 탈퇴를 마칠 수 있어야 한다.

카카오가 연결되지 않은 회원에 사용하는 오류 코드 `-101`만 연결 해제가 끝난 상태로 처리한다. 다른 오류를 성공으로 판단하면 연결이 남아 있는데도 회원 정보가 먼저 삭제될 수 있다. [카카오 오류 코드 안내](https://developers.kakao.com/docs/en/rest-api/error-code)

## 결과 (Consequences)

- 회원의 카카오 토큰을 보관하지 않아도 관리자 키와 사용자 번호로 연결을 해제할 수 있다.
- 카카오 연결 상태를 확인할 수 없으면 회원은 탈퇴를 다시 시도해야 한다.
