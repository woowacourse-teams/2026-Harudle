# 애플 로그인 연결 해제를 어떻게 처리할 것인가

## 결정 (Decision)

애플 로그인을 사용한 회원이 탈퇴하면 애플에 토큰 해제를 요청한다. 토큰은 해당 회원에게 발급된 접근 토큰 또는 갱신 토큰을 사용한다.

토큰과 인증 코드가 모두 없어 해제 요청을 할 수 없는 회원도 하루들 계정 삭제는 진행한다. 이 경우 회원에게 애플 계정 설정에서 하루들 연결을 직접 해제하도록 안내한다.

토큰이 있지만 애플 서버 오류나 통신 실패로 해제를 확인할 수 없다면 탈퇴를 중단한다. 회원은 다시 탈퇴를 시도할 수 있다.

## 근거 (Rationale)

하루들 회원을 삭제하는 것과 애플 로그인 연결을 해제하는 것은 별개의 작업이다. 회원 정보만 삭제하면 애플에 연결이 남을 수 있다.

애플의 토큰 해제 요청에는 접근 토큰 또는 갱신 토큰이 필요하다. 두 토큰과 인증 코드가 모두 없는 경우에도 계정 삭제 요청을 처리하고 직접 연결을 해제하도록 안내해야 한다. 토큰이 있는데 일시적인 오류로 해제 결과를 확인하지 못한 경우에는 해제 성공으로 판단하지 않고 다시 시도한다. [Apple 계정 삭제 안내](https://developer.apple.com/documentation/technotes/tn3194-handling-account-deletions-and-revoking-tokens-for-sign-in-with-apple)

## 결과 (Consequences)

- 토큰이 있으면 해당 토큰을 발급받을 때 사용한 client ID로 애플에 해제를 요청한다. 애플의 200 응답은 해제됐거나 이미 무효인 경우이므로 성공으로 처리한다.
- 토큰과 인증 코드가 모두 없다면 애플 연결의 직접 해제 안내가 필요하다.
- 애플 서버 오류나 통신 실패가 발생하면 회원은 탈퇴를 다시 요청해야 한다.
- 애플 토큰 해제와 하루들 DB 삭제는 별개의 작업이므로, 한쪽의 성공을 다른 쪽의 성공으로 취급하지 않는다.
