# 첫 페이지 반복과 5페이지 균등 순회로 피드 캐시 효과를 비교한다

## 배경

피드 첫 페이지만 반복하면 같은 이미지 키가 자주 나타난다. 여러 페이지를 고르게 조회하면 더 많은 키가 나타나므로 캐시의 효과를 첫 페이지 결과만으로 판단하기 어렵다.

## 고려한 방법

- 첫 페이지 반복만 실행하면 자주 노출되는 사진에서 캐시가 작동하는지 보기 쉽지만, 조회 범위가 넓어졌을 때의 동작은 알기 어렵다.
- 여러 페이지 순회만 실행하면 더 넓은 이미지 집합을 볼 수 있지만, 첫 페이지 반복에서의 효과를 분리하기 어렵다.
- 두 조건을 각각 실행하면 같은 캐시 설정이 서로 다른 조회 형태에서 어떤 결과를 내는지 비교할 수 있다. 캐시 켜기 전후의 실행 조건을 맞춰야 한다.

## 결정과 이유

첫 페이지 20개 반복과 첫 5페이지 총 100개 균등 순회를 각각 110, 120, 125, 130 RPS에서 비교한다. 125 RPS는 120과 130 사이에서 지연이 증가하는 구간을 좁혀 보기 위해 포함한다. 캐시를 켜기 전후 같은 데이터, 부하량, 측정 구간과 서버 준비 상태를 맞춘다. 실패율 0%를 적용하고 요청 누락이나 미완료를 성공으로 세지 않는다. 피드 응답 지연과 이미지 주소 제공률을 함께 본다.

## 실제 동작과 결과

별도 저부하 예열 없이 실행한 캐시 미적용 기준선에서 첫 페이지 반복은 네 단계 모두 안정화 중 보호 중단돼 본 측정 p95가 없다. 이후 실행한 5페이지 순회는 네 단계 모두 300초를 마쳤고, p95는 각각 145ms, 246ms, 482ms, 4,749ms였다. 130 RPS는 0.5초, 1초, 1.5초 기준을 모두 넘었다. 두 실행은 순서와 서버 준비 상태가 달랐으므로 페이지 수만의 효과는 확인할 수 없다. 캐시 적용 전후 비교 결과는 아직 없다.
