# 2026-08-27 관리자 사용자 상세 조회를 어떻게 구성할 것인가

- 작성일: 2026-08-27
- 작성자: 이산
- 결정 대상: 관리자 사용자 상세 조회의 사용량과 생성 이력 범위

## 결정

`GET /api/v1/admin/users/{userId}`는 사용자 기본 정보, 오늘 사용량, 최근 생성 이력 최대 5건을 반환한다.

- 사용량 행이 없으면 `usedCount = 0`과 사용자의 현재 일일 한도를 반환하며 DB에는 행을 만들지 않는다.
- 최근 생성 이력은 `createdAt`을 `requestedAt`으로 사용하고, `createdAt DESC, id DESC`로 정렬한다.
- 생성 상태는 `PROCESSING`, `SUCCEEDED`, `FAILED`를 모두 포함한다.
- 생성 이력 조회 시 일기가 삭제되었는지는 필터링하지 않는다.
- 탈퇴 사용자는 조회할 수 있지만 게스트 세션 사용자와 존재하지 않는 사용자는 `404`로 처리한다.
- 응답에는 이메일을 포함하지 않는다.

## 결과

- 상세 화면에서 사용자 상태·현재 사용량·최근 생성 상태를 한 번에 확인할 수 있다.
- 사용자별 한도와 날짜별 사용량 스냅샷 정책을 상세 조회에도 일관되게 적용한다.
- 실패로 일기가 삭제된 생성 작업도 관리자에게 보인다.

## 재검토 조건

- 최근 생성 이력의 조회 범위나 개수 제한을 관리자 요구에 맞게 변경해야 하는 경우
- 게스트 사용자도 관리자 화면에서 조회해야 하는 경우
