# 기본 프로필 이미지를 URL 대신 코드로 저장

- 작성일: 2026-10-10
- 작성자: 초록
- 상태: 채택

## 배경

사용자가 업로드하는 이미지가 아니라 서버가 제공하는 기본 이미지 5개를 사용한다. DB에는 이미 `profile_image_code` 컬럼이 있고, 공개 프로필 조회 계약은 이미지 URL을 반환한다.

## 검토한 대안

| 방식 | 장점 | 감수할 점 |
| --- | --- | --- |
| 회원별 이미지 URL 저장 | 조회 시 별도 변환 없이 사용할 수 있다. | 이미지 호스트나 경로 변경 시 회원 데이터도 수정해야 할 수 있다. |
| 이미지 코드 저장 후 URL 변환 | 회원에 배정된 이미지와 배포 경로를 분리한다. | 코드와 이미지의 대응 관계를 관리하는 공통 변환이 필요하다. |

## 결정

- 기존 컬럼을 유지하고 1~5 코드 중 하나를 서버가 최초에 랜덤 배정해 저장한다.
- 조회나 재로그인 때 다시 추첨하지 않으며, 같은 이미지 코드를 여러 회원이 사용하는 것은 허용한다.
- 프로필 조회 구현에서 저장된 코드를 URL로 변환하도록 한다. 피드, 댓글, 알림은 반환된 URL을 사용한다.

## 결과와 재검토 조건

이미지 주소 변경을 회원 데이터 수정과 분리할 수 있지만 코드와 이미지의 대응 관계를 유지해야 한다. 이미지가 늘어나면 검증 범위와 DB CHECK, URL 변환을 함께 변경한다. 사용자 업로드를 지원할 때 저장 모델을 재검토한다.
