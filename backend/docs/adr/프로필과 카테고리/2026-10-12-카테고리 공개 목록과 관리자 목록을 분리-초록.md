# 카테고리 공개 목록과 관리자 목록을 분리

- 작성일: 2026-10-12
- 작성자: 초록
- 상태: 채택

## 배경

사용자는 게시할 때 사용할 수 있는 카테고리만 보면 된다.
관리자는 사용을 꺼둔 카테고리도 확인해야 한다.

## 결정과 이유

하나의 API에 비활성 항목을 포함할지 옵션을 주는 방법도 생각했다.
하지만 누구에게 어떤 목록을 보여주는지 명확하게 나누는 게 더 이해하기 쉽다고 봤다.

- `GET /api/v1/categories`는 로그인 없이 활성 카테고리만 조회한다.
- `GET /api/v1/admin/categories`는 관리자만 전체 카테고리를 조회한다.
- 두 목록은 표시 순서대로 정렬하고, 순서가 같으면 ID가 작은 항목부터 보여준다.

조회 쿼리는 두 개로 나누고, 조회 서비스와 응답 형식은 같이 사용한다.
