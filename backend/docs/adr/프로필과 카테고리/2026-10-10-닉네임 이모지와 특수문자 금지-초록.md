# 닉네임 이모지와 특수문자 금지

- 작성일: 2026-10-10
- 작성자: 초록
- 상태: 채택

## 배경

공개 닉네임의 표시와 검증 기준을 단순하게 유지하기 위해 허용 문자를 명시한다.

## 결정

- NFC 정규화 후 한글 음절·자모(`가-힣`, `ㄱ-ㅎ`, `ㅏ-ㅣ`), 영문(`A-Z`, `a-z`), 숫자(`0-9`)와 일반 공백만 허용한다.
- 이모지, 특수문자, 보이지 않는 문자 및 그 밖의 문자는 거부하며 자동으로 제거하지 않는다.
- 앞뒤·연속 공백 금지와 공백 포함 1~10자 제한은 유지한다. Java Policy와 DB CHECK에 같은 문자 범위를 적용한다.
- 실패 시 `InvalidNicknameException`으로 HTTP 400과 `닉네임은 한글, 영문, 숫자와 공백만 사용할 수 있습니다.`를 전달한다.
