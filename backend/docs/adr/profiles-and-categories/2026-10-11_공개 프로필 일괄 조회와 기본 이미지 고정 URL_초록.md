# 공개 프로필 일괄 조회와 기본 이미지 고정 URL

- 작성일: 2026-10-11
- 작성자: 초록
- 상태: 채택

## 배경

피드, 댓글, 알림에서 여러 작성자의 닉네임과 이미지를 보여줘야 한다.
기본 이미지 5개는 모든 회원이 공유하며, 공개 프로필 조회 계약에는 URL 만료 시각이 없다.

## 결정과 이유

- 회원 ID를 모아 필요한 공개 정보만 DB 쿼리 한 번으로 조회한다. 작성자마다 DB를 호출하지 않는다.
- 탈퇴, 미배정 회원은 결과에서 제외한다. OAuth 이름을 대체 닉네임으로 공개하거나 조회 중 프로필을 배정하지 않는다.
- 기본 이미지 5개는 기존 프론트엔드 Nginx에서 고정 URL로 제공한다. 새 저장소 설정과 서명 URL 만료 처리가 필요 없다.
- DB에는 이미지 코드만 저장하고, `PROFILE_IMAGE_BASE_URL`과 코드로 URL을 만든다. S3·CDN으로 옮길 때 주소 설정만 변경할 수 있다.
- 이미지 경로에 버전을 넣고 기존 파일은 덮어쓰지 않는다. 오래 캐시해도 같은 URL은 같은 이미지를 의미한다.
- 회원 프로필은 별도 캐시 없이 현재 DB 값을 읽는다. 닉네임 변경은 다음 조회에 반영된다.

## 이후 확장

개인 이미지 업로드는 별도 S3 경로를 회원에게 연결하고, 조회 시 업로드 이미지를 우선 사용하도록 확장한다.
기본 이미지 코드는 복귀용으로 유지하고 `PublicProfileReader` 반환 계약은 유지한다.
이미지 선택·업로드 기능은 현재 단계에 포함하지 않는다.
