# 인프라 v2 설계 결정

RDS 대신 EC2에서 PostgreSQL을 직접 운영하는 구성을 설계한다.
결정한 내용과 실제 서버에 적용한 상태를 나누어 기록한다.

Prod의 복구 목표는 데이터 유실 최대 5분, 서비스 중단 후 1시간 이내 복구다.
이 목표를 위한 대기 DB와 장애 전환 방법은 별도 ADR에서 정한다.
