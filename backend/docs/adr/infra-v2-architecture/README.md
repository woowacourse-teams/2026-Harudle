# 인프라 v2 설계 결정

RDS 대신 EC2에서 PostgreSQL을 직접 운영하는 구성을 설계한다.
결정한 내용과 실제 서버에 적용한 상태를 나누어 기록한다.

EC2는 Dev 앱, Dev DB, Prod 앱, Prod DB의 총 네 대로 운영한다.
추가 EC2 비용을 들여 대기 DB를 운영하지 않는다.
Prod의 데이터 유실 최대 5분과 서비스 복구 4시간 목표는 유지하되,
외부 백업과 WAL로 복원하는 방법을 설계하고 실제 시험으로 달성 여부를 확인한다.
WAL은 PostgreSQL의 데이터 변경 기록이다. 백업 저장소와 전송 비용은 별도로 계산한다.
