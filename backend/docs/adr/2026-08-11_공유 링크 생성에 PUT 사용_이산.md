# 공유 링크 생성에 PUT 사용

그림일기에는 하나의 공유 링크만 존재할 수 있다.

공유 링크 생성 요청이 반복되더라도 새로운 링크를 계속 생성하지 않고, 동일한 공유 링크를 반환해야 한다.

공유 링크를 생성하고 반환할 때 `POST` 대신 `PUT`을 사용하는 이유는 다음과 같다.

- `POST`는 기본적으로 멱등성을 보장하지 않는다.
- `PUT`은 동일 요청을 여러 번 실행하더라도 최종 서버 상태가 같아야 하는 멱등 메서드다.

서버는 다음과 같이 처리한다.

1. 해당 그림일기의 공유 링크를 조회한다.
2. 공유 링크가 존재하면 기존 링크를 반환한다.
3. 공유 링크가 존재하지 않으면 새로 생성하여 반환한다.
