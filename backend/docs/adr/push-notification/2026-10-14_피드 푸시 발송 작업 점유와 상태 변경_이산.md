# 피드 푸시 발송 작업 점유와 상태 변경

- 작성일: 2026-10-14
- 작성자: 이산
- 결정 대상: 발송 작업을 고르고 결과를 DB에 안전하게 저장하는 방법

## 왜 필요한가

피드를 게시하면 알림을 받을 기기마다 발송 작업 하나를 DB에 저장한다. 서버가 여러 대라면 두 서버가 같은 작업을 동시에 고를 수 있다. 피드가 삭제되거나 기기 등록이 해제되면 아직 보내지 않은 알림을 멈춰야 한다. 작업을 처리하던 서버가 종료되면 다른 서버가 이어서 처리해야 한다.

## 발송 작업을 처리하는 순서

1. 피드 게시와 함께 기기별 발송 작업을 `PENDING`으로 저장한다. 이 저장은 피드 게시와 같은 DB 트랜잭션에서 끝난다.
2. `expire`는 피드 게시 후 24시간이 지난 미발송 작업을 `FAILED`로 바꾼다. 다른 서버가 아직 처리 중인 작업은 점유 시간이 끝난 뒤 바꾼다.
3. `claim`은 보낼 시간이 된 `PENDING` 작업 하나를 고른다. 처리하던 서버의 점유 시간이 지난 `PROCESSING` 작업도 다시 고를 수 있다. 다른 서버가 DB에서 잠근 작업은 기다리지 않고 건너뛴다.
4. `claim`은 고른 작업을 `PROCESSING`으로 바꾼다. 이번 점유를 식별할 `lock_token`을 새로 만들고 점유 시간을 5분으로 정한다. 시도 횟수도 1 늘린다. 여기까지 짧은 DB 트랜잭션에서 처리한다.
5. `target`은 전송 전에 피드, 사용자, 기기 등록, 로그인 세션, Refresh Token이 유효한지 확인한다. 유효하면 DB에 저장된 최신 FID와 버전을 읽는다. 하나라도 유효하지 않으면 대상이 없다는 결과를 돌려준다.
6. 실제 워커가 연결되면 대상이 있을 때 FCM 전송기를 호출한다. 대상이 없으면 `cancel`로 작업을 `CANCELLED`로 바꾼다. FCM 호출은 `claim`의 DB 트랜잭션 밖에서 한다.
7. FCM이 요청을 수락하면 `sent`로 `SENT`를 기록한다. 일시 오류라면 워커가 다음 시각을 계산하고 `retry`로 `PENDING`을 기록한다. 다시 보내면 안 되는 오류라면 `fail`로 `FAILED`를 기록한다. FCM의 수락만으로 기기에 실제 도착했는지는 알 수 없다.

현재 코드에는 `expire`, `claim`, `target`과 결과를 저장하는 메서드가 있다. **이 메서드를 순서대로 호출하는 워커는 아직 연결하지 않았다.** FCM 오류 분류와 다음 재시도 시각 계산도 다음 작업에서 연결한다.

## 상태가 뜻하는 것

| 상태 | 뜻 |
| --- | --- |
| `PENDING` | 보낼 시간이 되기를 기다리거나 재시도를 기다린다. |
| `PROCESSING` | 한 서버가 작업을 점유해 처리 중이다. |
| `SENT` | FCM이 전송 요청을 수락했다. 기기 도착을 확인한 상태는 아니다. |
| `CANCELLED` | 피드 또는 수신 대상이 유효하지 않아 전송을 멈췄다. |
| `FAILED` | 다시 보내지 않기로 했거나 피드 게시 후 24시간이 지났다. |

## 늦게 끝난 서버의 결과는 어떻게 처리하는가

서버 1이 작업을 점유한 뒤 종료되거나 처리가 지연되면 DB에는 `PROCESSING`이 남는다. 5분의 점유 시간이 지나면 서버 2가 같은 작업을 다시 점유하고 새 `lock_token`을 저장한다. 처리가 지연된 서버 1이 뒤늦게 결과를 기록하려 해도 저장된 `lock_token`이 다르므로 변경되지 않는다.

`sent`, `retry`, `fail`, `cancel`도 작업이 여전히 `PROCESSING`이고 `lock_token`이 같을 때만 상태를 바꾼다. 따라서 기기 등록 해제로 취소된 작업을 늦게 끝난 서버가 `SENT`로 덮어쓸 수 없다. 다만 유효성을 확인한 직후 기기가 해제되면 이미 시작된 FCM 요청은 회수할 수 없다.

## 확인한 내용

DB 통합 테스트로 두 서버의 점유 경합, 5분 뒤 재점유, 늦은 결과 무시, 최신 FID 확인, 유효하지 않은 대상 제외, 재시도 시각, 게시 후 24시간 종료를 확인했다. 다음 작업은 이 DB 처리와 FCM 전송기를 워커에서 연결하는 것이다.
