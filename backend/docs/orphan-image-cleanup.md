# 고아 이미지 자동 정리 제거

S3 생성 이미지 전체를 순회해 현재 DB에 참조가 없는 객체를 삭제하는 기능은 제거했다.
서로 다른 DB를 사용하는 환경이 같은 버킷과 prefix를 공유하면 다른 환경의 정상 이미지를
미참조 객체로 판단할 수 있기 때문이다.

고아 이미지 정리 스케줄러, S3 목록 조회 어댑터, 전용 설정을 등록하지 않는다.
기존 ORPHAN_IMAGE_MINIMUM_AGE, ORPHAN_IMAGE_CLEANUP_INTERVAL 환경 변수는 더 이상 사용하지 않는다.
변경은 새 애플리케이션 배포 및 기존 인스턴스 교체 후 적용된다.

개별 생성 요청에서 폐기된 업로드를 처리하는 기존 로직과 만료된 생성 작업의 상태 복구는 유지한다.
